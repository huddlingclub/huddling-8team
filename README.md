# 씻을까? — 허들링 클럽 8조

> 일어났을 때 **"씻을까?"** 를 누르면 **얼마나 씻고 나갈 수 있는지** 직관적이고 재미있게 알려주는 서비스

제한 시간 2시간 안에 만드는 MVP입니다. 시간 계산은 앱이, 재미있는 문구는 AI가 맡습니다.

## 한눈에 보기

1. **온보딩** — 나갈 시각, 필수 준비(옷 입기 등), 씻기 체크리스트(항목·시간·우선순위) 설정
2. **사용** — 일어나서 "씻을까?" 버튼 누르기
3. **판단** — `출발까지 남은 시간 − 필수 준비 시간` 안에서 우선순위 순으로 씻기 항목 채우기
4. **결과** — 코스 이름, 한 줄 안내, 할 수 있는/포기할 항목, 예상 꼬질도, 재촉 문구

**AI 역할 분담** : 시간·항목은 앱 계산값만 화면에 쓰고, AI는 문구 4종(코스 이름·한 줄 안내·포기 안내·재촉 문구)만 만든다.
AI가 2.5초 안에 못 주거나 실패하면 `data.js`의 기본 문구를 즉시 보여준다.

## 실행하기

| 상황 | 방법 | AI 문구 |
| --- | --- | --- |
| 가장 빠르게 화면만 보기 | `index.html` 더블클릭 | 기본 문구 (서버 없음) |
| 로컬 서버로 보기 | `python -m http.server 5173` 후 `http://localhost:5173` | 기본 문구 (`/api`가 없음) |
| AI 문구까지 확인 | `.env.example`을 `.env`로 복사 → `AI_API_KEY` 입력 → `npx vercel dev` | AI 문구 |

> `.env`는 `.gitignore`에 들어 있어 커밋되지 않습니다. **API 키는 절대 커밋하지 마세요.**
> 현재 보유한 키는 카카오맵(JS·REST)뿐이라, AI 키는 팀에서 정해야 합니다 → [피드백 안건](docs/03-팀-피드백-안건.md) 참고.

테스트: `npm test` (계산 로직 17개 + API 검증 9개, 의존성 없음)

데모 팁: 홈 화면 아래 **"테스트용: 현재 시각 바꿔보기"** 에 시각을 넣으면 08:15, 08:32 등 상황을 바로 재현할 수 있습니다.

## 폴더 구조와 담당 파일

```
├─ index.html        화면 구성 (4개 화면)
├─ style.css         디자인 (색은 :root 토큰만 바꾸면 전체 테마 변경)
├─ app.js            계산 로직 + 화면 동작 + API 호출
├─ data.js           기본값·기본 문구·꼬질도 단계 (문구 수정은 이 파일만)
├─ api/message.js    서버: 계산 결과를 받아 AI 호출 → 문구 검증 후 반환
├─ tests/            node:assert 테스트
└─ docs/             팀 공유 문서
```

| 역할 | 담당 파일 |
| --- | --- |
| 팀장 | 저장소 · Vercel 연결 · PR 머지 · 남는 시간에 테스트 |
| 화면 담당 | `index.html` · `style.css` (Figma 와이어프레임 → 실제 디자인 적용) |
| 기능 담당 | `app.js` · `api/` (버튼 동작, AI API 연결) |
| 기획·발표 담당 | `data.js` (화면 문구·예시 데이터), 휴대폰 테스트, 발표 준비 |
