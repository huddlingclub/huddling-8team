# 04 배포 (Vercel)

배포 주소: https://huddling-8team.vercel.app/

Vercel 이 GitHub 저장소(`huddlingclub/huddling-8team`)와 연결되어 있다(Git Integration).
별도 설정 파일 없이 정적 파일(`index.html` 등)과 `api/` 서버리스 함수를 자동으로 인식한다.

## 배포 흐름

| 상황 | 결과 |
| --- | --- |
| main 에 머지(push) | 프로덕션 배포 → 위 주소의 화면이 1~2분 안에 바뀐다 |
| PR 을 올리거나 브랜치에 push | 미리보기(Preview) 배포 → PR 에 Vercel 봇이 주소를 남긴다 |

화면 담당 PR 은 머지 전에 미리보기 주소로 확인하고, 머지 후 프로덕션 주소에서 한 번 더 본다.

## 확인할 설정 (Vercel 프로젝트 Settings)

- **Git > Production Branch**: `main`
- **Environment Variables**: `AI_API_KEY` (선택: `AI_MODEL`), Production 과 Preview 에 적용
  - 없으면 `/api/message` 가 503 을 주고 앱은 기본 문구를 보여준다(화면은 정상 동작).
  - 환경변수를 바꾼 뒤에는 재배포해야 반영된다.
- **Deployment Protection**: 미리보기 주소는 기본적으로 Vercel 로그인이 필요하다. 팀원이 확인하려면 Vercel 팀에 초대하거나 보호 설정을 조정한다.

## 배포가 안 바뀔 때

1. Vercel 프로젝트 > Deployments 에서 최신 배포의 상태와 빌드 로그를 본다.
2. 머지 커밋이 main 에 들어갔는지 확인한다.
3. 브라우저 캐시를 비우거나 강력 새로고침(Ctrl+Shift+R)한다.
